Лабораторная работа №3 - Шаблонизатор диалогов для NPC
В input.txt хранится текст письма от старосты деревни, содержащий
специальные теги-заглушки: <NAME>, <DAY> и <ITEM>. Программа должна
построчно считать текст и заменить все вхождения <NAME> на текущее
имя фермера, <DAY> — на номер текущего дня (current_day), а <ITEM> —
на текстовое название предмета, который сейчас лежит в нулевом слоте
инвентаря (inventory[0]). Готовый персонализированный текст письма
сохранить в output.txt.
